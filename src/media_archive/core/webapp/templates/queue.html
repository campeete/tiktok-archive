Worker

The queue is drained by a separate worker process. If "running" stays at zero while "pending" grows, no worker is active.

tiktok-archive worker

Or one-shot:

tiktok-archive worker --once

  • sync-creator — pull profile
  • tag — reserved
  • embed — phase 5

Status Flow

  • pending → running
  • running → done
  • running → failed (retry w/ backoff)
  • failed permanently after 3 attempts
